# 陸特3 合格道場 (ExamPrep-LandRadio3)

第三級陸上特殊無線技士の試験対策アプリ **モック版** です。Apple App Store で公開することを想定した iOS 風 UI をブラウザ上で確認できます。

## 概要

- **対象資格**: 第三級陸上特殊無線技士 (陸特3)
- **試験科目**: 無線工学 / 法規
- **ゴール**: スキマ時間に問題を解いて合格ラインを超える

## ファイル構成

| ファイル | 役割 |
| :-- | :-- |
| `index.html` | iPhone フレームを含む画面マークアップ |
| `styles.css` | iOS 風デザインシステム (カラー、カード、タブバー) |
| `app.js` | 画面遷移とモック問題バンク、クイズロジック |

## 画面構成

1. **ホーム**: 連続学習、進捗サマリ、今日のおすすめ
2. **学習**: 科目 (無線工学 / 法規) から選ぶ・模擬試験・復習
3. **クイズ**: 4択問題 + 解説
4. **結果**: スコアと次アクション
5. **統計**: 週間グラフ、分野別正解率
6. **設定**: アカウント、通知、プレミアム案内

## ローカル確認方法

```bash
# プロジェクト直下で
python3 -m http.server 8000
# → http://localhost:8000 にアクセス
```

画面幅 430px 以下ではデバイスフレームを外して全画面表示になります。

## 注意

- 収録されている問題はモック用のサンプルであり、実試験の過去問ではありません。
- 画像アイコンは絵文字・SF Symbols 風の文字で代替しています。
- リポジトリは **Private** 設定で管理します。

## 次のステップ (本実装の想定)

- SwiftUI での iOS ネイティブ移植 (iOS 17 以降)
- 過去問データベース (JSON → CoreData / SQLite)
- 学習履歴のオンライン同期 (iCloud / Firebase)
- App Store Connect 申請用メタデータとスクリーンショット
