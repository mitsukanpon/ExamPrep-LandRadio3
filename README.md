# 陸特3 合格道場 (ExamPrep-LandRadio3)

第三級陸上特殊無線技士の試験対策アプリ **モック版** です。Apple App Store で公開することを想定した iOS 風 UI をブラウザ上で確認できます。

## 概要

- **対象資格**: 第三級陸上特殊無線技士 (陸特3)
- **試験科目**: 無線工学 / 法規
- **ゴール**: スキマ時間に問題を解いて合格ラインを超える

## ファイル構成

| ファイル | 役割 |
| :-- | :-- |
| `index.html` | iPhone フレームを含む画面マークアップ |
| `styles.css` | iOS 風デザインシステム (カラー、カード、タブバー) |
| `app.js` | 画面遷移とモック問題バンク、クイズロジック |

## 画面構成

1. **ホーム**: 連続学習、進捗サマリ、今日のおすすめ
2. **学習**: 科目 (無線工学 / 法規) から選ぶ・模擬試験・復習
3. **クイズ**: 4択問題 + 解説
4. **結果**: スコアと次アクション
5. **統計**: 週間グラフ、分野別正解率
6. **設定**: アカウント、通知、プレミアム案内

## 問題の出典方針

- **収録問題はすべて本アプリ独自に作成した自作類題です。**
- 日本無線協会等が著作権を有する公式過去問は一切複製していません。試験範囲（電気通信術・無線工学・法規の学習範囲）に沿ってゼロから書き下ろしています。
- 類題ベースでまずリリースし、将来的に公式過去問の利用許諾取得を検討します。
- 条文要旨の解説は短文引用の範囲（出典明示）で留めます。

## 出題アルゴリズム（計画）

現状: 重要度（`importance`）による加重ランダム抽出のみ。

次フェーズで以下を追加予定:

- **SM-2 変形の忘却曲線**: 各問題に `ease` / `interval` / `lastSeenAt` / `correctStreak` を保持し、正解で間隔延長・誤答でリセット。
- **弱点重み**: `wrongCount / totalAttempts` を優先度スコアに加算。
- **出題優先度式**:
  ```
  score = w₁·忘却度 + w₂·誤答率 + w₃·重要度 + w₄·未出題ボーナス
  ```
- **新規:復習 = 3:7 の混合比**で出題。
- **模擬試験モード**は純粋ランダム（学習アルゴリズム無効）。

## アカウント方針

- **ログイン不要**でコア機能を利用可能にします（Apple 審査推奨、学習系の業界標準）。
- 学習履歴は端末内保存（UserDefaults / SwiftData）+ iCloud キーバリューストアで機種変時も自動同期。
- Sign in with Apple はランキング等オプション機能を追加する際にのみ検討。
